== PROBLEM 4: ALPHA DECAY SCHEDULE ==

Code uses: alpha_t = max(0.1, 1.0 * 0.9985^t)
This is exponential decay — not what standard LinUCB theory assumes (fixed
or slowly growing beta_T).

Paper needs to:
  - Add a sentence acknowledging this is a practical choice
  - Suggest wording: "We use a geometrically decaying exploration coefficient
    alpha_t = max(0.1, 0.9985^t) following standard empirical practice in
    neural-linear bandits. While the theoretical analysis assumes a fixed
    confidence radius beta_T, the decaying schedule improves finite-horizon
    exploitation. We verify in Appendix X that the qualitative results
    (reward multiplication when Assumption D holds) are robust to using
    a fixed alpha = 0.1."
  - Optional ablation: run small regime with fixed alpha=0.1 to verify

  - Internal LLM generation probability instead of V^{(1)} = cI

  over. The theoretical framework applies to this setting with V^{(1)}
